# Architecture

## Layers

```
HTTP ─▶ routes ─▶ middleware ─▶ controllers ─▶ services ─▶ repositories ─▶ db (Drizzle / Postgres)
                                    │              │
                                 schemas         lib (errors, jwt, health, resilience, logger)
```

| Layer             | Owns                                                                              | Must not                                 |
| ----------------- | --------------------------------------------------------------------------------- | ---------------------------------------- |
| `routes/`         | path → middleware → controller wiring                                             | call services, repositories or the db    |
| `middleware/`     | cross-cutting HTTP concerns: validation, auth, timeout, rate limit, errors        | business rules                           |
| `controllers/`    | read validated input, call one service method, map the result to a DTO and status | query data, catch errors to set statuses |
| `services/`       | business rules, transaction boundaries, domain errors (`AppError` subclasses)     | know about Express, `req` or `res`       |
| `repositories/`   | Drizzle queries for one aggregate; accept `db` or a transaction                   | commit, throw HTTP errors, call services |
| `db/`             | pool, schema, migrations, transaction runner                                      | import any layer above                   |
| `schemas/`        | Zod request/response schemas and DTO mappers                                      | contain logic beyond mapping             |
| `lib/`, `config/` | framework-free building blocks                                                    | import any layer                         |

Dependencies point one way. `.dependency-cruiser.cjs` fails `npm run lint` on a violation and on any cycle.

## Composition root

`src/container.ts` is the only file that calls the `create*` factories with concrete dependencies. Tests build the same container against a test database (`tests/helpers/test-app.ts`), or call a service factory with in-memory repositories.

## Request lifecycle

1. `pino-http` assigns or propagates `X-Request-Id` and attaches `req.log`.
2. `helmet`, CORS, JSON body (100 kB limit).
3. Health routes (no timeout, no rate limit).
4. Request timeout, global rate limit, auth rate limit on `/auth`.
5. Route → `validate()` → `authenticate` / `requireRole` → controller.
6. Thrown or rejected errors (Express 5 forwards async rejections) reach `errorHandler`, which emits problem+json.

## Errors

Services throw `AppError` subclasses with a stable `code`. Validation failures become 422 with per-field `errors[]`. Unknown errors become an opaque 500 and are logged with the stack. Clients branch on `code`, never on `detail`.

## Data

- One `postgres.js` pool per process, created in `index.ts` and closed on shutdown.
- Migrations are SQL files generated by drizzle-kit and committed; production never uses `drizzle-kit push`.
- Services own transactions through `TransactionRunner`. Repositories take an optional executor, so the same query runs inside or outside a transaction.
- Pagination is keyset (`created_at desc, id desc`) with an opaque cursor, backed by an index.

## Resilience

| Concern                                                  | Where                                               |
| -------------------------------------------------------- | --------------------------------------------------- |
| Fail fast on bad config                                  | `config/env.ts`                                     |
| Liveness vs readiness, critical vs optional dependencies | `lib/health.ts`, `controllers/health.controller.ts` |
| Timeouts, retries with jitter, circuit breaker           | `lib/resilience.ts`, `lib/http-client.ts`           |
| Request deadline                                         | `middleware/timeout.ts`                             |
| Graceful shutdown and fatal-error handling               | `lib/shutdown.ts`                                   |
