# Workflow Commands

Slash commands for common development workflows.

## Commands

| Command | Invocation | Description |
|---------|------------|-------------|
| `review-changes` | `/workflow-commands:review-changes` | Review uncommitted changes |
| `summarize-diff` | `/workflow-commands:summarize-diff` | Summarize branch diff vs base |

Commands are namespaced by plugin name in Cursor.
