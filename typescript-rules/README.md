# TypeScript Rules

Cursor rules for TypeScript coding standards.

## Rules

| Rule | Applies to | Description |
|------|------------|-------------|
| `prefer-const` | `**/*.{ts,tsx}` | Use `const` over `let` when possible |
| `no-console-log` | `**/*.{ts,tsx}` | Avoid `console.log` in production code |

Rules apply when editing matching files. They are available on request when `alwaysApply` is `false`.
