# i18n (react-i18next) — review checklist

Distilled from the `i18n` skill and `rules/i18n.mdc`. Applies to any new or changed user-facing string, date/number/currency formatting, or plural/RTL handling.

- A hardcoded user-facing string not passed through `t()`: JSX text, `aria-label`, `alt`, `title`, `placeholder`, `label`/`description` props, `sr-only` text (including the registry "Close"), `notify` toasts, zod validation messages, error-boundary fallback copy, loading/empty/error copy.
- An object, constant, or `constants.ts` holding English copy (`LABELS`, `MESSAGES`, `STATUS_LABELS`, `TextContent`, `shared/config/textContent.ts`) instead of keys in `en.json`. A union → label map must hold keys.
- Server data wrapped in `t()`, or a server-provided message replaced by invented copy.
- Copy under `src/locales/`, `shared/locales/`, or `shared/config/` instead of the owning slice's `locales/` or `shared/lib/i18n/locales/common/`.
- A generic string (`Cancel`, `Save`, `Retry`, `Close`) added to a feature's locale when `commonKeys` already has it.
- Prototype copy changed on the way into `en.json` without a spec reason.
- `t('list.emptyState')` or a key assembled at runtime instead of `t(usersKeys....)` / `commonKeys` (unless every variant is enumerated in the typed `keys.ts`).
- A feature importing another feature's `locales/keys.ts`.
- `models/` importing translation keys or calling `t()`.
- String concatenation for interpolation instead of `t(key, { name })`.
- A manual `count === 1 ? ... : ...` plural branch instead of the `count` option with `_one`/`_other` suffixes.
- Copy with embedded markup or a link split into concatenated fragments around JSX instead of one key rendered with `<Trans>`.
- `toFixed`, `toLocaleString`, or `Intl.*` constructed in a component instead of `shared/lib/i18n/format.ts`. Currency code taken from the locale instead of the money value.
- Physical Tailwind utilities (`ml-`, `mr-`, `left-`, `right-`) in layout that should be RTL-safe, instead of logical ones (`ms-`/`me-`, `ps-`/`pe-`, `text-start`, `start-`).
- A new key present only in a non-`en` locale file.

## Severity

A hardcoded user-facing string, an English string map, a raw key literal, or a missing `en` entry is **Must fix**. Formatter/RTL/`<Trans>` misses are **Should fix**.
