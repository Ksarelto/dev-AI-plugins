# i18n

Mechanism in `shared/lib/i18n/`. Copy lives in `features/{f}/locales/` and `shared/locales/common/`. Keys are typed. `models/` never imports translation keys.

## Evaluate

**Hard**

- Layout: `shared/lib/i18n/{config,format,index,keys}.ts`; `features/{f}/locales/{en.json,keys.ts}`; `shared/locales/common/{en.json,keys.ts}`. Provider in `app/providers/` (`I18nProvider`).
- `shared/lib/i18n/` contains no translation strings.
- `models/` must not import translation keys or call `t()`.
- UI uses `t(usersKeys....)` or `commonKeys` — not raw `'list.emptyState'` literals (except closed-set template keys enumerated in `keys.ts`).
- Each `locales/keys.ts`: `as const satisfies NestedKeysOf<typeof en>` (`NestedKeysOf` lives in `shared/lib/i18n/keys.ts`).
- Features must not import another feature's `locales/keys.ts`. Shared copy goes in `common`.
- Dates/currency: formatters from `shared/lib/i18n/format.ts` (`useCurrencyFormatter`, etc.) — not `toFixed(2)` or hardcoded format strings. Currency code comes from the money, not from the locale.
- `CustomTypeOptions.resources` in `shared/lib/i18n/config.ts` lists namespaces so `t()` args (including interpolation variables) type-check.
- Default locale `en` is the source of truth for key structure — a key in `de` missing from `en` is a bug.
- Interpolate with `t(key, { values })`, never by concatenating translated fragments. Plurals use `count` + `_one`/`_other`, not a manual branch. Sentences with links use `<Trans>`, not three concatenated keys.

**Judgment**

- Dynamic `t(\`status.${x}\`)` allowed only if every `x` is in the typed registry.
- A namespace missing from `CustomTypeOptions` (manual maintenance).

## How

```bash
ls src/shared/lib/i18n src/shared/locales src/features/*/locales
rg -n "useTranslation|from ['\"].*locales" src/features/*/models src/entities/*/model
rg -n "from ['\"]@/features/[^'\"]+/locales" src/features
rg -n "t\(['\"][^'\"]+['\"]\)" src --glob "*.tsx"
rg -n "toFixed\(|toLocaleString\(" src/features src/shared/ui
```

Open a `keys.ts` and confirm `satisfies NestedKeysOf`. Confirm `en.json` and `keys.ts` exist in pairs. Grep formatters vs ad-hoc number formatting in UI.
