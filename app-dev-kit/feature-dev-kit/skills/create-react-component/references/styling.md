# Styling Conventions (Tailwind + CVA)

Applies to all new code generated by the factory. Legacy styled-components remain in place; this guide governs FSD layer output.

---

## Semantic Tokens First

Never hardcode color values. Always use semantic CSS variable tokens via Tailwind utility classes.

| Token class | Meaning | Use for |
|-------------|---------|---------|
| `bg-background` | Page/panel background | Container backgrounds |
| `text-foreground` | Primary text | Body copy, headings |
| `bg-primary` / `text-primary-foreground` | Brand action color | Buttons, active states |
| `bg-destructive` / `text-destructive-foreground` | Error / danger | Delete buttons, error states |
| `text-muted-foreground` | Secondary text | Labels, captions, placeholders |
| `border-border` | Default border | Input outlines, dividers |
| `bg-accent` / `text-accent-foreground` | Hover highlight | List items, ghost button hover |
| `ring-ring` | Focus ring | Focus-visible outlines |
| `bg-card` / `text-card-foreground` | Card surface | Card components |

---

## DO / DON'T Table

| DO | DON'T |
|----|-------|
| `className="bg-background text-foreground"` | `className="bg-white text-gray-900"` |
| `cn(buttonVariants({ variant }), className)` | `` `btn ${isActive ? 'btn-active' : ''}` `` |
| `cva(...)` for multi-variant components | Long ternary chains in className |
| `motion-reduce:transition-none` on animated elements | Animating without respecting user preference |
| `sm:flex-row` for responsive layout | Hardcoded pixel breakpoints in inline styles |
| Extract repeated pattern to `ui-classes.css` after 3rd use | Copy-paste the same 5 utility classes a 4th time |

## `cn()` + CVA Pattern

```ts
import { cva, type VariantProps } from 'class-variance-authority'
import { cn } from '@/shared/lib/cn'

const badgeVariants = cva(
  'inline-flex items-center rounded-full px-2.5 py-0.5 text-xs font-semibold transition-colors',
  {
    variants: {
      variant: {
        default: 'bg-primary/10 text-primary',
        success: 'bg-green-100 text-green-800',
        destructive: 'bg-destructive/10 text-destructive',
        outline: 'border border-border text-foreground',
      },
    },
    defaultVariants: { variant: 'default' },
  },
)

interface BadgeProps extends React.HTMLAttributes<HTMLDivElement>, VariantProps<typeof badgeVariants> {}

export const Badge = ({ className, variant, ...props }: BadgeProps): JSX.Element => (
  <div className={cn(badgeVariants({ variant }), className)} {...props} />
)
```

## Utility Inline vs. Extracted

- Inline Tailwind utilities for one-off layouts (fewer than 3 uses across the codebase).
- Extract to `shared/ui/styles/ui-classes.css` when a pattern repeats 3 or more times:

```css
/* shared/ui/styles/ui-classes.css */
.card-panel {
  @apply bg-card text-card-foreground rounded-lg border border-border shadow-sm p-6;
}
.form-field-wrapper {
  @apply flex flex-col gap-1.5;
}
```

Reference with `className="card-panel"` — not with inline utilities repeated verbatim.

## Mobile-First Responsive

All responsive classes use the mobile-first `sm:` / `md:` / `lg:` / `xl:` prefix pattern.

```tsx
// Correct — mobile first
<div className="flex flex-col gap-4 sm:flex-row sm:gap-6">
```

---

## Dark Mode

Dark mode is handled entirely through CSS variable token reassignment in the `.dark` class on `<html>`. No `dark:` Tailwind class prefixes are needed when all colors use semantic tokens — the token values change automatically.

If a component requires a dark-specific override that cannot be expressed through tokens, use `dark:` as a last resort and add a comment explaining why.

---

## Animation / Motion

```tsx
// Always pair animations with motion-reduce:
<span className="animate-spin motion-reduce:animate-none" />
<div className="transition-all duration-200 motion-reduce:transition-none" />
```

---

## Legacy Interop Boundary

styled-components is allowed **only** in `shared/ui/` adapter components that wrap legacy Ant Design primitives. New components in `features/`, `entities/`, `widgets/`, and `pages/` use Tailwind + CVA exclusively.

```ts
// shared/ui/legacy-adapters/LegacyTable.styles.ts — ONLY place styled-components is acceptable
export const StyledTable = styled(AntTable)`
  .ant-table-header { background: var(--background); }
`
```
